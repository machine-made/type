The Reserved Font Name "machine-made" means: if you change a font and
distribute it, give it a name that does not contain "machine-made".

machine-made Sans is based on Plus Jakarta Sans by Gumpita Rahayu,
Tokotype. Plus Jakarta Sans has no Reserved Font Name. The
"machine-made" Reserved Font Name covers only the machine-made changes
(OFL FAQ 5.10).

The release zip files contain the `OFL.txt` of their family.
