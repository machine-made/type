# Licensing

This repository has two licences: one for the fonts and one for the
code.

| Path | Licence | Licence file |
| --- | --- | --- |
| `fonts/weft/**` | SIL Open Font License 1.1, Reserved Font Name "machine-made" | `weft/OFL.txt` |
| `weft/loom/glyphs.py`, `weft/loom/extended.py` (the stroke tables that define the outlines; each file says so in its header) | SIL Open Font License 1.1, Reserved Font Name "machine-made" | `weft/OFL.txt` |
| `fonts/shuttle/**` | SIL Open Font License 1.1, Reserved Font Name "machine-made" | `shuttle/OFL.txt` |
| `shuttle/loom/glyphs.py`, `shuttle/loom/kerning.py` (the glyph and kerning tables that define the outlines and spacing; each file says so in its header) | SIL Open Font License 1.1, Reserved Font Name "machine-made" | `shuttle/OFL.txt` |
| `shuttle/reference/**` | The approved sketch (engine, page, screenshot): same licence as the font it defines | `shuttle/OFL.txt` |
| `fonts/sans/**` | SIL Open Font License 1.1, Reserved Font Name "machine-made" (copyright: Plus Jakarta Sans Project Authors and machine-made Sans Project Authors) | `sans/OFL.txt` |
| `sans/sources/**` | SIL Open Font License 1.1, as for `fonts/sans/` | `sans/OFL.txt` |
| `sans/upstream/**` | Upstream Plus Jakarta Sans credit files, unchanged (SIL OFL 1.1) | `sans/upstream/OFL.txt` |
| `proofs/**` | Images and reports made from the fonts: same licence as the font they show | `weft/OFL.txt`, `sans/OFL.txt` or `shuttle/OFL.txt` |
| Every other file, for example the rest of `weft/loom/` and `shuttle/loom/`, `weft/tools/`, `weft/scripts/`, `weft/tests/`, `shuttle/tools/`, `shuttle/scripts/`, `shuttle/tests/`, `sans/scripts/`, `sans/tests/`, `site/`, `.github/` | Apache License 2.0 | `LICENSE` |

The Reserved Font Name "machine-made" means: if you change a font and
distribute it, give it a name that does not contain "machine-made".

machine-made Sans is based on Plus Jakarta Sans by Gumpita Rahayu,
Tokotype. Plus Jakarta Sans has no Reserved Font Name. The
"machine-made" Reserved Font Name covers only the machine-made changes
(OFL FAQ 5.10).

The release zip files contain the `OFL.txt` of their family.
