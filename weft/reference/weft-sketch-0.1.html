The FRAG axis

From clean to broken on one slider

Up to 15, FRAG only notches the joints, which keeps body text safe. From 16 it cuts across strokes, narrower than the stroke itself. Past 50 the pieces drift, shrink and drop out.

About this sketch

What it shows, and what it does not yet

  • Letters are drawn from centre-line strokes. The real font will be outlines written by the generator, the loom, and compiled by fontmake.
  • No spacing or kerning pass yet. Every character sits in a 12-unit cell.
  • A letter breaks the same way each time it appears, as it will in a variable font. Reweave picks another pattern.
  • Thread is here so you can judge it. It ships after the first release.
  • The OCR gate and Fontspector checks have not run on this. They start in phase 2.
